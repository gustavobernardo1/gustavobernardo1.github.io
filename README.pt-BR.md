# Portfólio científico

Código-fonte do site pessoal de Gustavo Bernardo Brito, construído com Quarto.

Instale o Quarto: https://quarto.org/docs/get-started/. Execute `quarto preview` localmente e `quarto render` para gerar o site em docs/. Verifique as páginas geradas, depois versione docs/ (incluindo um arquivo docs/.nojekyll vazio) e configure o GitHub Pages para publicar a partir de main /docs. A publicação não foi verificada.

**Nota de manutenção:** as instruções acima traduzem o README original; o fluxo de publicação atual está em `.github/workflows/publish.yml`, que publica temporariamente a página de manutenção.
