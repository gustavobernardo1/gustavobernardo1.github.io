# Scientific portfolio

Personal website source for Gustavo Bernardo Brito, built with Quarto.

Install Quarto: https://quarto.org/docs/get-started/. Run `quarto preview` locally and `quarto render` to build into docs/. Verify rendered pages, then commit docs/ (including an empty docs/.nojekyll file) and configure GitHub Pages to deploy from main /docs. Deployment has not been verified.
